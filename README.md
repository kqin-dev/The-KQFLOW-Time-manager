# Kairos — The-Kairos-Time-manager

> A command-line tool that integrates time management and a TODO list, base on Go.
>
> 每天向前一点的时间管理器：每日 TODO、长期 GOAL、番茄钟与专注计时、历史统计，全部装在一个终端看板里。

Kairos 是一个用 Go 编写的命令行时间管理工具。它编译成**单个可执行文件**，不依赖运行环境，拷贝到任意机器上从终端执行即可使用。

## 安装

### 直接使用发行版

下载 `kair.exe`，放到任意目录，把它所在目录加入 `PATH`，然后在终端输入：

```powershell
kair
```

### 从源码构建

```powershell
git clone https://github.com/kqin-dev/The-Kairos-Time-manager.git
cd The-Kairos-Time-manager
go build -ldflags "-s -w -X main.version=0.1.0" -o kair.exe ./cmd/kair
```

需要 Go 1.24 或更高版本。项目只依赖 [Bubble Tea](https://github.com/charmbracelet/bubbletea) 与 [Lipgloss](https://github.com/charmbracelet/lipgloss)，构建后是纯静态单文件。

## 看板结构

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 按时段变化的问候语、当前逻辑日与星期、系统时间、今日专注时长 |
| 左栏上 | **TODAY · 固定**：长期坚持的事项，每天自动出现 |
| 左栏下 | **TODAY · 临时**：当天临时安排，可选择性继承昨日未完成项 |
| 中间栏 | Kairos 渐变 ASCII 艺术字、今日完成度、功能选项、随机字条 |
| 右栏 | **GOAL**：与日期无关的长期目标，勾选后归档到当天 |
| 底栏 | 时段看条：正计时为流动光带，其余按时段着色显示进度 |

## 快捷键

### 导航

| 按键 | 作用 |
| --- | --- |
| `tab` / `shift+tab` | 在「中间选项 → 左固定 → 左临时 → 右 GOAL」之间循环切换 |
| `h` / `l` | 左右切换栏位 |
| `j` / `k` | 上下移动 |
| `g` / `G` | 跳到首项 / 末项 |
| `1` / `2` / `3` | 直接切到菜单 / 左栏 / GOAL |

### 编辑

| 按键 | 作用 |
| --- | --- |
| `space` / `enter` | 勾选完成（GOAL 勾选后会归档到当天） |
| `a` | 添加 TODO（焦点在固定栏时添加固定 TODO） |
| `A` | 添加 GOAL |
| `e` | 重命名选中条目 |
| `t` | 为选中条目添加子任务 |
| `d` | 删除选中条目（会先确认） |
| `r` | 从昨日继承：固定 / 未完成 / 两者 |

### 计时

| 按键 | 作用 |
| --- | --- |
| `enter`（中间栏） | 打开计时菜单：番茄钟 / 倒计时 / 正计时 / 自定义 |
| `space` | 计时中暂停或继续 |
| `enter` | 计时中结束，并把实际时长归档到所属 TODO |
| `esc` | 计时中中断，已用时长仍会记录 |

### 其它

| 按键 | 作用 |
| --- | --- |
| `?` | 打开 / 关闭帮助 |
| `q` / `esc` | 返回看板，或退出 |
| `ctrl+c` | 随时退出（进行中的计时会先记录再退出） |

## 日界线

熬夜用户可以把「一天」的起点推后。设置页（`设置 / Settings` → `c`）把日界线设为 `04:00` 之后：

- 凌晨 2 点的工作仍然算作前一天；
- 到凌晨 4 点，TODAY TODO 才自动切换到新的一天；
- 问候语也跟着用户的作息走，凌晨 2 点仍是夜晚。

## 数据存放

数据默认放在可执行文件同级的 `kairos-data/`，因此把 `kair.exe` 和这个目录一起拷走就能带走全部进度。

```
kairos-data/
  config.json      配置（日界线、默认时长、昵称、时区）
  goals.json       与日期无关的长期 GOAL
  days/
    2026-10.json   按日切分的数据库，一天一条记录
  backup/          每次写入前的自动备份，保留最近 5 个版本
```

也可以用环境变量 `KAIROS_HOME` 或命令行参数指定位置：

```powershell
kair --data-dir D:\my-kairos
$env:KAIROS_HOME = "D:\my-kairos"; kair
kair --where     # 只打印当前数据目录
```

### 数据安全

终端被意外关闭不会丢数据：

- 每次写入都是「先写临时文件 → 落盘 → 原子改名」，不会留下半个 JSON；
- 每次写入前保留上一版到 `backup/`；
- 计时中断、退出、跨日都会立即落盘，进行中的计时段也会先记录再退出；
- 主文件损坏时自动回退到最近的可用备份。

## 开发

```powershell
go test ./...                            # 全部单元测试
go vet ./...                             # 静态检查
go run ./cmd/kair                        # 直接运行
```

代码结构：

```
cmd/kair/            入口：命令行参数与启动
internal/clock/      逻辑日、日界线、问候语、时长格式化
internal/config/     配置读写与数据目录定位
internal/model/      TODO / GOAL / TASK / 计时记录等数据结构
internal/store/      按日分库的本地存储、备份与恢复
internal/ui/         Bubble Tea 界面：看板、设置、历史、帮助
```
