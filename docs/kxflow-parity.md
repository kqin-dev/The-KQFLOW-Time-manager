## 结论：还差多少？

**必须补（否则不能切默认）**：

1. ✅ **子任务**（`internal/ui/app.go:648` `enterSubTasks` /
   `toggleSelectedTask`）——已实现：`enter` 进、`esc` 退、
   `space` 勾选并回写父条目、`l → 加子任务…` 添加。
2. ⬜ **随手记编辑**（`internal/ui/note.go`）——需要多行输入。
   **这是最后一项必补。**
3. ✅ **继承昨日**（`internal/ui/app.go:887` `askCarry`）——已实现：
   `l → 继承昨日（日期）…`，四选一且每项带数量；
   规则复用 `store.CarryFixed/CarryFloating`（去重、只带未完成）。
4. ✅ **跳到首/末**（`g/G`）——已实现，列表与目标栏都有。

**可以后补（不阻塞切默认，但要如实告知）**：

5. ⬜ 收藏自定义专注方案（`savedplans.go`）
6. ⬜ 时段切换提醒三项（`notify.go` / `notify_ntfy.go`）
7. ⬜ `N` 之外的小写快捷键（`a`/`e`/`d`/`t`/`r` 等）——
   **这是刻意的设计差异**：v3 用 `l` 统一入口，不再堆单键快捷键
   （用户反馈"不应该保留数字作为快捷键"的延伸）。
   代价是每次多按一次键，收益是按键数量不随功能增长。

**已超过 2.1.0 的**：视图设置、按需按键提示、插件化架构。
