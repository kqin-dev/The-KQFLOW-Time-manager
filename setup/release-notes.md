# KQFLOW 2.1.0

这一次加了四块功能、两处数据保护，另外**明确了一件重要的事**（见下面的「关于已知问题」）。

## 新功能

- **标签**：TODO / GOAL 可打标签，内置常见预设（工作 / 学习 / 生活 / 健康…）也可自定义。
  本版标签用于**标记与显示**，不做筛选。一个条目最多 8 个标签。
- **截止时间（DDL）**：按 `D` 给条目设截止——TODO 设时间点、GOAL 设日期。
  设了截止的条目会出现在**右栏新增的 DDL 面板**里，按时间排序并显示倒计时，
  临近截止会高亮。截止只是提示，不会阻止你勾选或删除。
- **收藏自定义专注方案**：编好的自定义时段可以存下来反复用，也能当模板改，
  不用每次重编。
- **时段切换提醒**：三种方式，按"注意力距离"分档，**各自可关、默认全关**：
  - **流光**——做在中间栏的 LOGO 上（换更亮的配色、加快流动、首尾加记号）；
  - **提示音**——系统响铃；
  - **手机推送**——通过 [ntfy.sh](https://ntfy.sh) 推到手机，**不需要注册账号**。

  设置页里有「**提醒 · 测试**」：按 enter 立刻演示一次，并告诉你哪几项因为没打开
  而跳过。

## 数据保护

- **数据版本保护**：数据文件来自更新版本的程序时会**拒绝启动并说明原因**，
  而不是硬着头皮读错。宁可给你一句明确提示，也不在后台悄悄改坏数据。
- **计时保护**：计时进行中再次启动计时会被拒绝。旧行为会**静默丢弃**正在进行
  的时长——这是本版修掉的一个会真正丢数据的 bug。

## 关于已知问题（重要）

我们在开发过程中反复遇到同一类现象：**长段中文在宽终端下换行诡异，看起来像被截断**。
同一个问题连续修了四轮都没根治，于是我们停下来找根因，结论是：

> 这不是四个 bug，而是**一个结构性问题**：界面缺少统一的渲染层。每个页面自己算宽度、
> 自己折行、自己摆列，一处假设与真实面板差一两列，就表现为"文字被截断""栏位消失"。
> 而且这些问题**只在特定终端宽度下出现**，开发环境里极难复现。

因此这一版**停止继续打补丁**，并把下面这些如实写进文档：

- 宽终端下长段文字的换行观感仍未根治（**观感受损，不丢数据**）；
- 提示音使用终端响铃，部分终端或系统设置下不响；
- 界面只在 Windows 终端上验证过。

**下一步**是把界面重写成**分层的渲染引擎（KXFLOW）**，让布局只有一处权威实现，
并在渲染前强制保证「不超宽、不超行、不越界」，从结构上消除这类问题；同时为后续的
**社区插件**（磁贴式扩展）打接口基础。设计构想见
[ROADMAP.md](https://github.com/kqin-dev/The-KQFLOW-Time-manager/blob/main/ROADMAP.md)。

**v2.1.0 的定位是原型**：核心功能都可用、数据格式稳定，3.0 主要替换布局与渲染层，
业务逻辑尽量平移。所以现在可以放心用，数据也不会因为 3.0 而失效。

## 从 2.0.1 升级

**直接装到同一位置即可覆盖，你的数据不会被覆盖或删除。**

从 2.0.1 升到 2.1.0 是纯增量：标签、截止时间、收藏方案、提醒设置都是新字段，
老数据读进来会自动补上默认值（没有标签、没有截止、提醒全关）。**不需要手工迁移。**

> 反向是**不允许**的：2.1.0 写过的数据会被 2.0.1 拒绝启动（数据版本保护）。
> 如果你需要回退，请先把 `kqflow-data` 备份出来。

## 功能（2.0.1 已有的部分）

- **每日 TODO**：分「固定」（每天自动出现）与「临时」两块独立面板，各有边框
- **子任务**：每个 TODO / GOAL 都可以拆子项，完成情况回写父条目
- **GOAL**：与日程无关的长期目标，完成或取消时在长期库与当天归档之间双向移动
- **四种计时**：番茄钟 / 倒计时 / 正计时 / 自定义时段；专注时长、休息时长、段数全部可配置
- **计时归档**：无论正常结束还是中途打断，实际时长都写入当天记录并累计到条目
- **随手记 / 日记**：中间栏里的多行编辑器，按日保存、过日重置，可选显示在看板上
- **连续 7 天统计**：滚动窗口的竖向柱状图
- **历史统计**：最近若干天的完成度、专注时长、GOAL 数、最投入的条目
- **可配置日界线**：熬夜党可以把「今天」的起点设到 04:00
- **随机字条**：看板中间栏滚动的便签，支持自定义多条
- **数据自愈**：读入时自动清理悬空引用与异常字符

## 安装说明

- **安装位置**：默认 `C:\Program Files\KQFLOW`。如果不小心选了桌面、下载或临时目录，向导会提醒你换一个。
- **加入 PATH**：默认勾选，请保持勾选——这样在任意终端直接输入 `kqf` 就能启动。
- **升级**：新版本装到同一位置即可直接覆盖，**你的数据不会被覆盖或删除**。
- **卸载**：会问你数据怎么处理，**默认保留**；要删除必须再确认一次。

## 输入法与鼠标

- **可以直接用输入法打字**。唯一区别是**候选词窗口的位置**：终端不向程序报告光标坐标，
  候选窗会贴在终端窗口的某个角落。文字一点不差地进到输入框，不影响使用。
- **默认不接管鼠标**：一旦接管，终端就无法用鼠标选中文本。需要时可在 `config.json`
  里把 `mouse` 设为 `true`。
- 目前只提供 **Windows x64** 的预编译包；代码本身跨平台，其它平台可从源码构建。

## 数据存在哪

默认是 `kqf.exe` 同级的 `kqflow-data/`，也可以用 `KQFLOW_HOME` 环境变量指定到别处。
里面是可读的 JSON，随时能自己查看或改。
