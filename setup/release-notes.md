# KQFLOW 2.0.1

这是 KQFLOW 的第一个发布。本项目此前叫 Kairos，本次更名并重置版本号。

> 2.0.1 修掉一个偶发问题：Windows 上原子写盘的最后一步（改名覆盖）可能因为
> 杀毒实时防护、索引服务或同步盘的**瞬时占用**而失败，界面上会冒出一行
> 「保存失败」。现在改为退避重试，不再因此报错。数据从未损坏——改名失败不会
> 影响原文件。

## 为什么改名

原名字 `Kairos` 是希腊语常用词（καιρός，"恰当时机"），已被大量注册使用，其中还包含一家同做时间管理工具的中国公司，以及若干商业产品。对一个长期维护的开源项目来说，这个名字既难注册、也难搜索。

`KQFLOW` 取自作者缩写 **KQ**（Kevin Quinn）+ 心流 **flow**，是自造词：可注册性更高，搜索唯一性更好，也与作者的另一款同技术路线工具 `ICFlow` 构成同一系列。

> 改名发生在原型阶段，外部使用者为零，因此没有历史包袱、也不需要复杂的迁移。**KQFLOW 与任何同名产品或公司均无关联。**

## 从 Kairos 升级

如果你装过 Kairos，请先卸载它再安装 KQFLOW —— 新版的安装标识是全新的，两者会被系统当作不同程序。

Kairos 的数据目录是 `kairos-data`，KQFLOW 改为 `kqflow-data`。想保留旧数据的话，把目录改个名即可：

```powershell
Rename-Item 'C:\Program Files\Kairos\kairos-data' 'kqflow-data'
```

环境变量也从 `KAIROS_HOME` 改为 `KQFLOW_HOME`。

## 下载哪个

| 文件 | 适合谁 |
| --- | --- |
| `KQFLOW-2.0.0-setup.exe` | **推荐**。安装向导会问装到哪、默认把目录加进 PATH，之后在任意终端输入 `kqf` 即可 |
| `kqf-2.0.0-windows-amd64.exe` | 绿色版。放到任意目录、把该目录加入 PATH 就能用，数据存在同级 `kqflow-data` |

## 功能

- **每日 TODO**：分「固定」（每天自动出现）与「临时」两块独立面板，各有边框
- **子任务**：每个 TODO / GOAL 都可以拆子项，完成情况回写父条目
- **GOAL**：与日程无关的长期目标，完成或取消时在长期库与当天归档之间双向移动
- **四种计时**：番茄钟 / 倒计时 / 正计时 / 自定义时段；专注时长、休息时长、段数全部可配置
- **计时归档**：无论正常结束还是中途打断，实际时长都写入当天记录并累计到条目
- **随手记 / 日记**：中间栏里的多行编辑器，按日保存、过日重置，可选显示在看板上
- **连续 7 天统计**：滚动窗口的竖向柱状图（归一化相对高度，空间不够会自己变矮）
- **历史统计**：最近若干天的完成度、专注时长、GOAL 数、最投入的条目
- **可配置日界线**：熬夜党可以把「今天」的起点设到 04:00
- **随机字条**：看板中间栏滚动的便签，支持自定义多条
- **数据自愈**：读入时自动清理悬空引用与异常字符，老数据不会越用越乱

## 安装说明

安装向导里有几件事值得留意：

- **安装位置**：默认 `C:\Program Files\KQFLOW`。如果不小心选了桌面、下载或临时目录，向导会提醒你换一个。
- **加入 PATH**：默认勾选，请保持勾选——这样在任意终端直接输入 `kqf` 就能启动。
- **升级**：新版本装到同一位置即可直接覆盖，**你的数据不会被覆盖或删除**。如果换了安装目录，向导会检测到旧数据并询问是否复制过去。
- **卸载**：会问你数据怎么处理，**默认保留**；要删除必须再确认一次。

## 输入法与鼠标

- **可以直接用输入法打字**。中文、日文等组字输入法在 Windows 终端里工作正常，上屏的文字会正常进入输入框。
  唯一区别是**候选词窗口的位置**：终端不向程序报告光标坐标，所以候选窗不会跟在光标旁边，
  而是贴在终端窗口的某个角落。文字一点不差地进到输入框，只是候选窗看着有点远，不影响使用。
- **默认不接管鼠标**：一旦接管，终端就无法用鼠标选中文本，会给复制粘贴带来不便。
  确实需要鼠标的话，可以在 `config.json` 里把 `mouse` 设为 `true`。
- 粘贴当然也支持：在别处打好中文 `Ctrl+C`，回到 KQFLOW 打开输入框后 `Ctrl+V` 即可。
- 目前只提供 **Windows x64** 的预编译包；代码本身跨平台，其它平台可以从源码构建。

## 数据存在哪

默认是 `kqf.exe` 同级的 `kqflow-data/`，也可以用 `KQFLOW_HOME` 环境变量指定到别处，方便备份和迁移。里面是可读的 JSON，随时能自己查看或改。
